============
volkszaehler
============

Das Plugin sendet Itemwerte bei Änderung an einen laufenden Volkszähler-Server.

Voraussetzungen
================

Ein installierter und laufender Volkszähler-Server wird benötigt.

Konfiguration
=============

Die Informationen zur Konfiguration des Plugins sind unter :doc:`/plugins_doc/config/volkszaehler`
beschrieben.

Item-Attribute
--------------

**vz_uuid** ist die UUID des Kanals (Channel) auf dem Volkszähler-Server, an den der Itemwert
gesendet werden soll.
